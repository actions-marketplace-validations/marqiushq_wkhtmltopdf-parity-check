# Sample templates

Four business documents from the [wkhtmltopdf parity suite](https://github.com/marqiushq/wkhtmltopdf-parity) (`corpus/everyday`, CC0), which the README's examples convert. `made-by-wkhtmltopdf/` holds the PDFs wkhtmltopdf 0.12.6 made of them with `--page-size A4 --margin-top 12mm --enable-local-file-access`, for the example with a baseline.
